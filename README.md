# RE:VERSE AI — Engenharia Reversa feita por IAs

## 1. Sobre o projeto

O RE:VERSE AI é uma landing page educativa desenvolvida para a disciplina **Desenvolvimento Front-End para Web**, com o objetivo de apresentar como a Inteligência Artificial pode auxiliar na engenharia reversa de softwares.

O projeto aborda a análise de código, a segurança digital, as limitações da IA e a importância da verificação humana na interpretação dos resultados.

1. Baixe ou extraia a pasta do projeto.
2. Abra a pasta no Visual Studio Code ou no explorador de arquivos.
3. Abra o arquivo `index.html` em um navegador.

## 6. Principais prompts utilizados

**Prompt 1 — Estrutura HTML**

"Ajude-me a criar uma landing page educativa sobre engenharia reversa feita por Inteligências Artificiais, utilizando HTML5 semântico. Inclua cabeçalho com menu interno, apresentação do tema, três cards informativos, uma seção explicando o processo, uma chamada para ação e rodapé acadêmico."

**Prompt 2 — Estilização CSS**

"Ajude-me a estilizar a landing page utilizando CSS3, com identidade visual tecnológica, gradientes nos cards, sombras, espaçamento adequado, efeitos de interação e organização com CSS Grid."

**Prompt 3 — Responsividade**

"Revise o CSS para que os cards e o restante da página se adaptem a computadores, tablets e celulares, evitando que os elementos ultrapassem a largura da tela."

## 7. Propriedades CSS novas testadas

### 7.1. `linear-gradient()`

* **Elemento:** cards e seções da página.
* **Finalidade:** criar transições suaves entre duas ou mais cores.
* **Teste realizado:** alterar as cores e o ângulo do gradiente para observar as diferenças visuais.
* **Resultado:** permite criar uma identidade visual mais moderna e diferenciar os cards.

### 7.2. `box-shadow`

* **Elemento:** cards e etapas do processo.
* **Finalidade:** adicionar sombras para criar profundidade e destacar os elementos.
* **Teste realizado:** modificar os valores de deslocamento, desfoque e transparência da sombra.
* **Resultado:** a sombra ajuda a separar os cards do fundo e reforça a hierarquia visual.

### 7.3. `clamp()`

* **Elemento:** títulos e textos da página.
* **Finalidade:** ajustar o tamanho da fonte de maneira flexível, respeitando um valor mínimo e um máximo.
* **Teste realizado:** modificar os valores mínimo, preferencial e máximo para observar a mudança da tipografia em diferentes larguras de tela.
* **Resultado:** ajuda a manter os textos legíveis e proporcionais em dispositivos diferentes.

**Observação:** os testes descritos nesta seção devem ser realizados e confirmados antes da entrega.

## 8. Responsividade e usabilidade

O layout utiliza CSS Grid para organizar os cards e media queries para adaptar a disposição dos elementos a diferentes tamanhos de tela.

A página também apresenta links internos, efeitos de `:hover`, indicação visual de foco com `:focus-visible` e transições simples.

## 9. Uso da Inteligência Artificial

O ChatGPT foi utilizado como ferramenta de apoio à aprendizagem para auxiliar na elaboração da estrutura HTML, na estilização CSS, na correção de problemas de layout e na compreensão das propriedades utilizadas.

O código foi desenvolvido e ajustado de forma iterativa, com o objetivo de compreender as regras aplicadas e personalizar o resultado.

## 10. Considerações finais

O projeto demonstra como HTML5 e CSS3 podem ser utilizados para desenvolver uma página informativa, visualmente organizada e responsiva. A atividade também permitiu explorar novas propriedades CSS e compreender melhor a importância de testar e ajustar o código durante o desenvolvimento.
